웹사이트 이미지 관리

주의사항

웹사이트 코드가 생성되지 않았습니다. 이미지를 관리하려면 먼저 코드 생성 페이지에서 웹사이트 코드를 생성해주세요.

이미지 관리 안내

이 페이지에서는 생성될 웹 사이트에서 사용되는 이미지를 관리할 수 있습니다.
이미지 설명은 사이트를 제작하는 도중에만 사용되며, 최종적으로 코드에는 이미지의 주소(URL)만 기록됩니다.

이 주소를 지정하는 방법은 다음과 같습니다:
• AI에게 이미지를 직접 생성 요청 후 만들어진 이미지 주소 사용 => 이미지 설명 입력 후 '이미지 생성' 버튼 클릭, 생성된 이미지 중 선택
• AI에게 웹에서 이미지를 검색 요청 후 검색된 이미지 주소 사용 => 이미지 설명 입력 후 '이미지 검색' 버튼 클릭, 검색된 이미지 중 선택
• 직접 웹에서 이미지를 찾아서 주소 입력 => 직접 입력란에 URL 입력 후 '가져오기' 버튼 클릭

주소를 입력하여 새 이미지에 미리보기가 정상적으로 표시되는 경우 저장 버튼을 클릭하여 사용할 이미지를 최종적으로 지정할 수 있습니다.
